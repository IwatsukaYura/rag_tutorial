Q04【Medium / 条件判断型】

期待される正解：
  以下の3つの場合：
  (1) 本人または第三者の生命、身体、財産その他の権利利益を害するおそれがある場合
  (2) 当社の業務の適正な実施に著しい支障を及ぼすおそれがある場合
  (3) 法令に違反することとなる場合

根拠文書：DOC-001（第8条）
評価のポイント：
  - 3つの条件をすべて列挙すること
  - 部分的な回答（1〜2条件のみ）は不正解とすること

  情報セキュリティポリシーには年齢に基づく特別な区分は設けられていない（全ユーザー共通のアクセス制御・暗号化等の技術的措置が適用される）。

根拠文書：DOC-001（第10条）、DOC-003（全体）

  - 存在しない保護措置を捏造しないこと

Q09【Hard / 複数情報統合型】
質問：業務を外部に委託する際、個人情報の保護に関してどのような義務や手続きが定められていますか？

期待される正解（要約）：
  [プライバシーポリシー観点（DOC-001 第6条より）]
  当社は利用目的の範囲内で業務を外部委託できる。委託先に対して必要かつ適切な監督を行う義務がある。

  [業務委託契約書観点（DOC-004 第7条より）]
  受託者は個人情報を委託業務目的のみに使用し、安全管理措置を講じ、第三者提供禁止、業務終了後の返還または消去義務を負う。

根拠文書：DOC-001（第6条）、DOC-004（第7条）
評価のポイント：
  - 2文書の情報を矛盾なく統合すること
  - 委託者側の義務（DOC-001）と受託者側の義務（DOC-004）をそれぞれ正確に区別すること

Q10【Hard / 複数情報統合型】
質問：情報漏えいが発生した場合、セキュリティポリシー上の社内手続きと、プライバシーポリシー上の外部対応の両面から、それぞれの対応手順を教えてください。

期待される正解（要約）：
  [社内手続き（DOC-003 第7章より）]
  ①セキュリティインシデント窓口に即時報告 → ②情報システム部の指示によるネットワーク切断等の初動措置 → ③記録の保全 → ④インシデント対応チームによる原因調査・再発防止策策定

  [外部対応（DOC-001 第5条・第8条より）]
  法令に基づき行政機関への報告義務がある場合（個人情報保護法上の重大インシデント等）は法務・コンプライアンス部の指導のもとで対応する。

根拠文書：DOC-001（第5条）、DOC-003（第7章）
評価のポイント：
  - 社内手続きの4つのステップが順序通り抽出されること
  - 社内手続きと外部対応を混同しないこと
  - 存在しない情報（例：具体的な報告義務の閾値）を捏造しないこと
