■ データセットの目的

法律・規約・ポリシー系テキストを対象として、以下2つの観点でRAGシステムを評価する。

(1) 検索精度（Retrieval Accuracy）
    - 質問に対して正しい文書が上位に検索されるか
    - 関連性の低い文書が上位に混入しないか

(2) 回答生成の正確性（Generation Accuracy）
    - 検索された文書から正確な情報が抽出されるか
    - 存在しない情報を捏造（ハルシネーション）していないか
    - 複数文書をまたぐ質問に対して情報を正確に統合できるか

■ Q&Aセットの構成（qa_test_set.txt）

合計10問。難易度別の内訳：
  - Easy（単一文書・明示的キーワード）：Q01〜Q03（3問）
  - Medium（単一文書・暗示的 or 複数条件）：Q04〜Q07（4問）
  - Hard（複数文書横断・統合）：Q08〜Q10（3問）

■ 推奨評価方法

各QAについて以下のスコアを記録することを推奨する。

検索精度スコア（Retrieval Score）：
  3点：期待される根拠文書がすべてTop-3に入っている
  2点：期待される根拠文書の一部がTop-3に入っている
  1点：Top-5に入っている
  0点：Top-5に入っていない

回答生成スコア（Generation Score）：
  3点：期待回答のすべての要素が含まれ、誤情報がない
  2点：期待回答の主要要素は含まれるが一部欠落がある
  1点：部分的に正しいが誤情報または重大な欠落がある
  0点：誤情報が多い、または全く回答できていない

■ 注意事項

- 本データセットは架空の企業・個人情報を使用したサンプルデータである。
- 実際の法的アドバイスや企業規約として利用することは想定していない。
- 文書間の整合性は概ね保たれているが、検証の観点から意図的にドキュメント間に微妙な補完関係を持たせている。
